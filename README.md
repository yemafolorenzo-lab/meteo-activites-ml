# meteo-activites-ml

Application de recommandation d'activités personnalisées basée sur les prévisions météorologiques et l'intelligence artificielle

## Stack Technique
- **Backend :** FastAPI (Python 3.12)
- **IA :** TensorFlow / Keras, Scikit-learn, Pandas
- **Frontend :** React.js
- **Méthodologie :** Scrum (4 Sprints d'une semaine)

## Structure du Projet
- `/backend` : API et logique serveur
- `/frontend` : Interface utilisateur React
- `/ml` : Scripts d'entraînement et datasets
- `/docs` : Documentation du projet (Cahier des charges, etc.)
